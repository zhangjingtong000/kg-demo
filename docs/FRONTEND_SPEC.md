# 前端页面规格

## 页面架构

```
/upload         上传页
/result/{id}    结果页（3D 图谱 + 聊天）
/history        历史记录（可选）
```

---

## 页面 1：上传页 `/upload`

### 布局

```
┌─────────────────────────────────────────────┐
│  Logo / 标题                                │
│                                             │
│         ┌───────────────────────┐            │
│         │                       │            │
│         │   拖拽 PDF 到此处      │            │
│         │   或 点击选择文件       │            │
│         │                       │            │
│         └───────────────────────┘            │
│                                             │
│  文件名: sample.pdf ✓                        │
│                                             │
│  模型:  ○ 云端  ○ 本地                       │
│  分块:  [ 500 字 ▼]                         │
│                                             │
│         [ 开始解析 ]                         │
│                                             │
└─────────────────────────────────────────────┘
```

### 功能点

| 元素 | 行为 |
|------|------|
| 拖拽区 | 支持拖拽 PDF 文件到区域内，或点击弹出文件选择 |
| 文件名校验 | 只接受 .pdf，显示文件名 |
| 云端/本地切换 | 选择 LLM 后端 |
| 分块大小 | 下拉选择（300/400/500/600 字）|
| 开始解析按钮 | 调用 `POST /upload`，完成后跳转到 `/result/{id}` |

### 状态

- 空状态：拖拽区显示引导文字
- 已选文件：显示文件名 + 开始按钮亮起
- 上传中：拖拽区替换为 loading 动画


## 页面 2：结果页 `/result/{id}`

### 布局

```
┌──────────────────────────────────────────┬─────────────┐
│  ← 返回上传    KG名称    [分享] [导出]     │             │
├──────────────────────────────────────────┤   聊天面板   │
│                                          │             │
│                                          │  Agent 头像  │
│        3D 知识图谱                        │             │
│        (我们已有的 Three.js 画布)          │ "哪些动作    │
│                                          │  练腿？"    │
│        · 点击聚焦                         │             │
│        · 拖拽旋转缩放                     │ → Squats   │
│        · 悬停高亮相邻节点                  │   训练      │
│        · 拖节点 + 回弹                     │ Quadriceps  │
│                                          │             │
│                                          │ → Deadlifts │
│                                          │   训练      │
│                                          │ Hamstrings  │
│                                          │             │
│                                          │             │
│                                          ├─────────────┤
│                                          │ [输入框 📤] │
├──────────────────────────────────────────┴─────────────┤
│  📊 27 节点 · 35 边 · 20.6s · 来源：sample.pdf        │
└────────────────────────────────────────────────────────┘
```

### 功能点

**3D 画布区域**（左侧，约占 70% 宽度）
- 渲染我们的 3D 知识图谱（复用 index3d-bounce.html 的逻辑）
- 数据来源：`GET /graph/{id}` 返回的 nodes + edges
- 交互：点击聚焦、拖拽旋转缩放、悬停高亮、拖节点回弹
- 聚焦时：扩散暗度 + 高亮环 + 相机跳到正面视角
- 节点大小按类型区分（可选）

**聊天面板**（右侧，约占 30% 宽度）
- Agent 对话风格（非普通聊天框）
- 输入框 + 发送按钮
- 每条消息显示 Agent 回答 + 引用来源（边的关系）
- 引用的来源在图谱上高亮对应路径（可选联动）

**顶部栏**
- ← 返回按钮（回到上传页）
- 图谱名称（可编辑）
- 分享按钮（复制链接）
- 导出按钮（导出 JSON / 图片）

**底部状态栏**
- 节点数、边数、处理耗时、源文件名
- 统计信息的简洁展示

### 3D 画布与聊天联动（可选，加分项）

- 用户问 "哪些动作练腿？"
- 后端返回 sources：[Squats→Quadriceps, Deadlifts→Hamstrings]
- 前端在 3D 画布上高亮这两条边
- 聊天面板显示文字回答 + 可点击的来源引用


## 页面 3：历史记录 `/history`（可选）

```
┌─────────────────────────────────────────────┐
│  历史图谱                                    │
│                                             │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐     │
│  │ sample   │ │ paper   │ │ notes   │     │

│  │ 2h前     │ │ 昨天    │ │ 3天前   │     │
│  └──────────┘ └──────────┘ └──────────┘     │
│                                             │
└─────────────────────────────────────────────┘
```

卡片点击跳转到 `/result/{id}`。


## 全局组件

| 组件 | 说明 |
|------|------|
| 导航栏 | Logo + 上传 / 历史 / 关于 |
| Loading | 解析中的进度动画（SSE 推送进度）|
| Toast | 错误/成功提示 |
| 主题 | 深色背景（与 3D 画布统一）|

## SSE 进度推送（后端需补充）

当前后端是同步返回。改成 SSE 需要：

```
POST /upload → 返回 { task_id }
GET  /task/{task_id}/progress  (SSE)

事件：
  event: progress
  data: {"step": "parsing", "progress": 20, "message": "正在解析 PDF..."}

  event: progress
  data: {"step": "extracting", "progress": 60, "message": "正在抽取实体... 已找到 15 个"}

  event: complete
  data: {"graph_id": "32adec12"}
```

前端监听 SSE，更新进度条。完成后跳转 `/result/{id}`。
