# 知识图谱探索流

> 状态：已确认（2026-07-30）
> 目标：默认沉浸，选择即解释；知识图谱始终是主舞台，界面只在需要时提供上下文。

## 核心原则

1. **图谱优先**：初始状态下，3D 知识图谱占据主要画面；详情、文档和问答均默认收起。
2. **占位式信息层**：侧栏不覆盖图谱。打开侧栏后，Three.js 舞台根据剩余可用区域平滑重取景，让图谱为面板让位。
3. **直接操控**：点击图谱中的对象直接进入对应信息，不设置冗余的“查看详情”中间按钮。
4. **可追溯**：实体、关系和问答答案都可以回到文档原文证据和页码。
5. **渐进披露**：用户先看到整体，再进入节点、关系、证据与问答；每一步保留上一步的上下文。

## 六个交互状态

### 1. 全局概览

- KG 全屏展示，左右面板隐藏。
- 仅保留轻量顶部导航、搜索入口与节点/关系统计。
- 用户可旋转、缩放、平移并悬停查看节点。

### 2. 节点聚焦

- 触发：单击节点，或从搜索结果进入节点。
- 图谱执行现有 BFS 关系环聚焦与相机移动。
- 当前节点和相关路径高亮，无关部分按图距离平滑变暗。

### 3. 自动检查器

- 节点聚焦后，右侧毛玻璃检查器自动滑入。
- 图谱不被覆盖：画布可用区域缩小，图谱和相机平滑左移/重取景，确保选中节点及其邻居仍舒适可见。
- 检查器包含：**概览**（名称、类型、描述）、**关系**（邻居和关系边）、**证据**（原文片段、页码、抽取元数据）。
- 在检查器内选择相邻节点时，检查器保持打开，内容交叉淡入；不反复关闭、重新弹出。

### 4. 关系溯源

- 触发：在检查器中选择一条关系，或直接在图中选择关系。
- 仅突出关系两端节点和对应边；边显示轻量的源→目标流光。
- 右侧显示关系解释、来源文本和页码；用户可继续跳转到目标节点。
- 顶部记录简短面包屑，例如：`Document / Squat / Trains / Quadriceps`。

### 5. 沉浸探索

- 触发：用户主动点击 Explore，或从概览进入全屏模式。
- 所有非必要栏位淡出，只保留最小导航、搜索和退出提示。
- 该状态不自动出现，避免打断首次概览和答辩说明。

### 6. 问答与证据

- 触发：用户在底部输入框提问。
- 回答以轻量面板呈现，并在图中同步标记支持答案的实体和关系路径。
- 每条回答可展开查看引用关系和原文证据。

## 退出与恢复规则

| 操作 | 结果 |
|---|---|
| `Esc` | 收起右侧检查器，保留当前节点聚焦与图谱姿态。 |
| 点击画布空白或“返回全局” | 关闭检查器、取消聚焦，恢复全局概览。 |
| 关闭沉浸探索 | 恢复概览导航；不清除当前图谱数据。 |
| 切换相邻节点 | 保持检查器与聚焦状态，平滑更新相机、图形强调与内容。 |

## 对后续实现的约束

- Three.js 渲染与 UI 面板共享一个“可用视区（safe area）”状态：左、右、上、下任何占位面板变化时，图谱都必须重新取景，而非被 CSS 覆盖。
- 当前 `index3d-bounce.html` 的节点聚焦、邻接高亮、拖拽与回弹逻辑应作为探索态基础；后续将硬编码图数据替换为后端 `/graph/{id}` 返回的数据。
- 后端图数据需补充来源页码、文档片段/块标识与抽取元数据，才能支撑证据面板。
- 问答接口返回的 `sources` 必须可映射到前端图中的节点与边，以便高亮证据路径。
