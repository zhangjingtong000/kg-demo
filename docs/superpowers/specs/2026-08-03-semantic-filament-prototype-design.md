# 语义星云丝状体原型设计

## 目标

验证知识图谱全局概览中，3 至 5 个星云之间的连接能否像宇宙网的丝状体一样表达跨主题关系，而不退化为密集的普通连线。

本原型回答一个问题：用户能否一眼区分强关联、弱关联和未关联的星云，并理解从星云进入局部实体图的入口。

## 范围

- 新建独立、明确标为 prototype 的全局概览页面。
- 使用固定的 3 至 5 个示例星云及聚合关系，不接真实 PDF 聚类。
- 仅实现星云悬浮、丝状体强调和点击进入意图的视觉反馈。
- 不修改 `web/index3d-bounce.html` 的 80 节点细节图。
- 不实现右侧检查器、真实主题聚类、持久化或跨层数据接口。

## 视觉与交互设计

星云是高密度的知识结点，之间的关系为轻微弯曲的三维丝状体，而不是直线。每对星云最多绘制一条聚合连接：

1. 强关联使用较宽但低对比的光带，靠近两个星云时更亮，中央更细。
2. 中关联使用更细、更暗的弧线。
3. 弱关联默认不绘制，悬浮任一端点时才以低亮度出现。
4. 未关联星云之间保留空洞，不以装饰线补齐。

悬浮星云时，仅该星云相关的丝状体升亮，并显示单个低速光粒子向另一端移动。粒子是关系的提示，不承担方向性或因果性含义。单击星云只显示“进入该主题局部图”的过渡反馈，后续接入真实详情页时替换为实际导航。

## 数据模型

原型使用以下最小模型：

```js
{ id, name, summary, position, size, color, entityCount }
{ source, target, strength: 'strong' | 'medium' | 'weak', relationCount }
```

`relationCount` 只决定展示强度，不会伪造实体级关系。正式实现时，这些字段由真实主题聚类和跨簇边聚合产生。

## 验收标准

- 默认画面不出现完整蜘蛛网，弱关联保持隐藏。
- 强、中关联在深空背景上可区分，但不盖过星云。
- 悬浮一个星云时，只有关联丝状体和一个低速粒子被强调。
- 页面可旋转、缩放，桌面视口下稳定运行。
- 原型与当前 80 节点详情图互不影响。

## 非目标

本原型不评价真实主题聚类质量，也不提交为最终星云页。完成视觉决策后，保留决策结论，删除原型或将被验证的渲染部件移入正式实现。
