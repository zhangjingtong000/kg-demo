## 当前阶段结论（非最终）

S0 与 S1 都未满足协议中的“P95 ≤ 16.7ms”不卡顿线；因此不能据此宣称当前高保真模式还有可用的 UI、背景或更多节点余量。S1 的拖拽回弹是当前最差的已测场景，说明全量曲线边刷新和全量标签随动是后续应优先拆解与量化的候选成本。

该结论只覆盖已完成的 S0、S1、DPR 1、纯 KG 场景。S2–S4、DPR 2、相机旋转和 UI 预算尚未完成，不能据此推导最终规模阈值。
